# Hi, I'm Paolo 👋

Full-stack software developer based in Santiago, Chile, with 9+ years building production
systems: communication platforms, CRM workflows and financial integrations (Equifax, Transbank).

My recent independent work includes a live healthcare scheduling platform, serverless
appointment reminders and document generation tools.

I work with JavaScript/TypeScript, Node.js and PHP/Laravel across backend services and
user interfaces.

## Selected work

- **Min-URL** — A URL shortener and software engineering lab: microservices monorepo with
  hexagonal architecture, 230+ automated tests and CI/CD. Currently developing its core
  functionality and preparing reproducible performance experiments.

- **Cataterapia** (live at [cataterapia.cl](https://cataterapia.cl)) — A website and appointment
  workflow for an occupational therapy practice, integrating scheduling, reminders and
  external services. Local SEO results: top 4 on Google, 80% organic patient acquisition.

- **devsalud-cataterapias-reminder** — Serverless appointment reminders for the same practice:
  Deno + Supabase Edge Functions + PostgreSQL, with privacy-first personal data handling.

- **Executives Communication Manager** — A Laravel/Vue MVP I developed individually for a
  financial-sector client: communication scheduling, permissions, activity logs and debt-collection
  law compliance.

- **BrochuresAI** — A React/FastAPI application that generates brochures from website content
  using an LLM integration and PDF rendering, with SSRF mitigation and Redis-based quota control.

## Technologies

- Backend: Node.js, TypeScript, NestJS, Express, PHP, Laravel, Deno
- Frontend: React, Vue, Astro, HTML and CSS
- Data: PostgreSQL, MySQL, Redis, Supabase
- Tools: Git, Docker, GitHub Actions

## Contact

Open to backend and full-stack opportunities in Chile and remote across LATAM.
